# simplifyit.com.pl

Statyczna strona Simplify IT: `index.html`, `assets/styles.css`, `assets/main.js`, fonty w `assets/fonts/` (Geist, licencja OFL, hostowane lokalnie, bez zapytań do zewnętrznych CDN).

Bez kroku budowania. Wystarczy wgrać zawartość repozytorium na serwer (np. przez FTP do `public_html`) albo podpiąć pod Netlify, Vercel lub GitHub Pages.

Do potwierdzenia przed publikacją:
- adres e-mail `kontakt@simplifyit.com.pl` (występuje w `index.html` kilka razy, także w danych JSON-LD),
- czasy etapów, „odpowiedź w 24 h”, 30 dni wsparcia i ceny „od …” na kartach usług,
- lista narzędzi i tekst w sekcji „Kto za tym stoi”,
- link do LinkedIn albo kalendarza, jeśli ma się pojawić w kontakcie.

Liczby na dashboardach i w arkuszu w pierwszej sekcji to dane przykładowe.
